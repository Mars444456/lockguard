# Readability and result layout — 2026-10-31

The public demo's SQL example is now aligned with the page instead of rotated. Shared styles use larger text and controls, and the mobile SQL editor has a shorter initial height while remaining resizable. The quick-access panel is preserved.

The public result starts with the inferred table lock, rule findings and affected tables. Five hypothetical load metrics are grouped in a closed disclosure with an explanation of their limits. Technical descriptions and SQL recommendations can be expanded separately.

The demo waits for an explicit check, supports Ctrl/Cmd+Enter and resets stale results when input or PostgreSQL version changes. Shared SQL links continue to run their supplied example. UPDATE displays ROW EXCLUSIVE rather than a hard-coded ACCESS SHARE. Both the page and printable report leave unmodelled DML timing, pool and loss estimates unclaimed. Summary read/write compatibility uses the same PostgreSQL conflict matrix as the explorer, including EXCLUSIVE and SHARE ROW EXCLUSIVE.
