## Реализовано

- Неподдерживаемые SQL-конструкции получают CRITICAL LG-000 и `analysisComplete: false`. DO, функции, триггеры, savepoint, неизвестные команды и неизвестные части ALTER TABLE больше не получают успешный вердикт. Такие ошибки нельзя подавить обычным ignore правила. Генератор фаз отклоняет неполный анализ.
- Незакрытые кавычки, dollar-quote и блоки комментариев отклоняются. Исправлены вложенные комментарии и разделение токенов через комментарии.
- Позднее CREATE TABLE не подавляет предупреждения раннего индекса. Таблицы из предыдущего файла больше не считаются гарантированно пустыми. После DML предположение о пустоте новых таблиц сбрасывается.
- Ключи хранятся как SHA-256 хеши; при создании секрет возвращается один раз. Список ключей содержит только префиксы. В dashboard добавлено окно копирования нового секрета. Известный встроенный demo-ключ больше не создаётся.
- При загрузке существующего JSON старые ключи преобразуются в хеши с сохранением ID, известный demo-ключ отзывается. Другие существующие секреты продолжают работать. Настроенный DEFAULT_API_KEY используется только для начального создания хешированной записи.
- Повреждённый JSON и ошибки записи теперь приводят к явной ошибке. При неудачном сохранении восстанавливается последнее успешно сохранённое состояние в памяти. Эксклюзивный файл блокировки и сравнение версии на диске предотвращают молчаливое затирание данных другим процессом.
- AutoSplitter сохраняет исходный SQL в `originalSql`, выставляет `requiresReview`, добавляет предупреждение об операциях, не перенесённых в фазы. Файлы помечены DRAFT и не перезаписываются. В DDL-фазах сбрасывается также statement_timeout.
- Браузерное ядро генерируется из src/core командой `node scripts/build-browser.js` (также `npm run build:browser`). Отдельная ручная реализация удалена. CI проверяет актуальность сборки; тест сравнивает браузерные и серверные результаты.
- В статическом playground экранируются сообщения и SQL-рекомендации; ошибки анализа отображаются пользователю и сбрасывают старый результат. Убраны основные гарантии «100% safe» из вердиктов. Оценка контекста больше не обещает гарантированный outage.
- Счёт с демонстрационными реквизитами явно помечен «ОБРАЗЕЦ — НЕ ДЛЯ ОПЛАТЫ», API возвращает templateOnly. Версия package.json приведена к версии CLI 1.1.0.

## Оставшиеся ограничения

Это по-прежнему консервативный частичный анализатор, а не полный PostgreSQL parser. LG-000 закрывает обнаруженные неподдерживаемые конструкции, но не доказывает семантическую корректность всего допустимого SQL. Вызовы функций внутри SELECT/DML и сложные выражения требуют полноценного AST и каталога БД. Проверки существования/порядка индексов и ограничения статической модели схемы остаются.

AutoSplitter выпускает черновой план: все исходные операции и свойства схемы не переносятся автоматически. Нужны тесты выполнения на отдельной PostgreSQL и дальнейшая работа над эквивалентностью преобразований. Файлы в каталоге генерации могут остаться частично записанными, если ошибка возникнет посреди нескольких фаз; существующие файлы сохраняются.

JSON-хранилище поддерживает один процесс записи. Второй процесс получает ошибку при устаревшем состоянии, а не автоматическое слияние. После аварийного завершения может остаться `.lock`; его следует удалять только убедившись, что процесс остановлен. Для нескольких серверных экземпляров нужна транзакционная БД.

Реальные платежи, подпись GitHub webhook, загрузка SQL из PR, отправка проверок в GitHub и живой watchdog не реализованы. Для их проверки нужны выбранный провайдер, параметры интеграции и тестовая PostgreSQL. Никакие внешние сообщения, платежи и развёртывания не выполнялись. Rate limiting и нагрузочная проверка публичного API также остаются отдельной задачей.

Для административного доступа по-прежнему необходим LOCKGUARD_ADMIN_TOKEN. Изменения существующего JSON вступят в силу при следующей загрузке сервера; пользовательский .env не редактировался.
