# Сайт, вход и поддержка проекта

Основной публичный адрес: https://mars444456.github.io/lockguard/.

На 31 октября 2026 года сервер LockGuard в интернете ещё не размещён. На публичном сайте работает браузерная проверка SQL. Кнопка «Войти» открывает объяснение и ссылку на локальный кабинет. Полей для ввода пароля на GitHub Pages нет; сайт не отправляет данные авторизации на сторонний адрес.

Локальный кабинет: http://localhost:3000/#account после `npm start`. Адрес `localhost` всегда относится к компьютеру посетителя, а не к компьютеру автора проекта. Фрагмент `#account` сразу открывает форму входа или профиль текущей сессии.

## Когда появится сервер

1. Разместить Node.js 24+ приложение на сервере с постоянным диском, HTTPS и собственным публичным адресом. Статику и `/api/v1/` отдаёт одно приложение; обходить проверки Origin или включать межсайтовую отправку паролей не требуется.
2. Задать на сервере `NODE_ENV=production`, `APP_URL=https://адрес-сервера`, постоянный путь `LOCKGUARD_DB_FILE`, каталог резервных копий и нужные закрытые настройки. Реальный `.env`, базу, резервные копии и ключи не коммитить. Проверить регистрацию, вход, выход и сохранность данных после перезапуска.
3. В `config/site.json` заполнить `applicationUrl` корневым HTTPS-адресом этого сервера, например `https://app.example.com`. Это пример адреса, не действующий сервер LockGuard.
4. Выполнить `npm run build:browser` и опубликовать изменения. Кнопка «Войти» на GitHub Pages начнёт открывать настоящий серверный кабинет с `#account` вместо окна о недоступности. До заполнения адреса не показывать регистрацию как доступную через интернет.

Публичный сайт и серверный кабинет пока имеют отдельные страницы и общий набор стилей. Эта правка добавляет понятную точку входа и общую поддержку проекта; она не объединяет весь код двух интерфейсов и не развёртывает сервер.

## Донат

Восстановлена исходная ссылка автора из истории репозитория: https://www.donationalerts.com/r/marswwu.

Одинаковые кнопки в шапке сайта и приложения, а также блок поддержки генерируются из `config/site.json` и `src/ui/support.html`. Сборки браузерной версии и документов сохраняют эти элементы. Ссылка открывает DonationAlerts в новой вкладке; LockGuard не проводит списания, не хранит данные карты и не активирует Pro по донату.

Источник о возможностях хостинга: [GitHub Pages — статический хостинг](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages).
