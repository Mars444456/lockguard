            🚨 ACCESS EXCLUSIVE: Fatal Table Lock (Full Outage Risk)
          

          

            Blocks all table operations: reads (SELECT), writes (INSERT, UPDATE, DELETE), indexes, and schema modifications. If a slow query is running, DDL queues behind it, and subsequent SELECT queries pile up (Head-of-Line Blocking), crashing connection pools and triggering HTTP 504 Gateway Timeouts.
          

          

            ⛔ Blocks: SELECT
            ⛔ Blocks: INSERT / UPDATE / DELETE
            ⛔ Blocks: CREATE INDEX
            ⛔ Blocks: VACUUM
